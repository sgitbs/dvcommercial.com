DV Commercial Website — Upload Instructions

1. Extract this ZIP file.
2. Upload every file inside the dvcommercial-site folder to the ROOT of your GitHub repository.
3. Keep index.html named exactly as it is; Vercel uses it as the homepage.
4. The form and branding settings should be tested after deployment. Check the site using a private/incognito window.
5. Before public launch, verify brokerage wording, DRE license number, required MGR Real Estate / Fair Housing disclosures, contact details, and the destination for form submissions.
